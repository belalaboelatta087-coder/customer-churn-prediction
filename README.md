# Customer Churn Prediction

## Project Overview
This project uses Machine Learning to predict whether a telecommunications customer is likely to leave the company (customer churn).

The project includes a Streamlit web application with an interactive dashboard, customer analytics, and individual churn predictions.

## Features
- Interactive dashboard with customer statistics.
- Customer churn distribution visualization.
- Churn analysis by contract type and payment method.
- Monthly charges and customer tenure analysis.
- Individual customer churn prediction.
- Estimated probabilities for customer retention and churn.
- Dark-themed interface built with Streamlit and Plotly.

## Machine Learning
The final model uses **Logistic Regression with SMOTE** to address class imbalance during training.

The saved model and decision threshold are loaded by the application. The threshold used for prediction is **0.60**.

### Test Results
- Accuracy: 76.44%
- Precision (Churn): 54.43%
- Recall (Churn): 68.98%
- F1-score (Churn): 60.85%

These metrics describe the model's evaluation on the test dataset.

## Run Locally

1. Install the required packages:

   ```bash
   python -m pip install -r requirements.txt
   ```

2. Start the application:

   ```bash
   python -m streamlit run app.py
   ```

3. Open the local URL displayed in the terminal.

## Deployment
The application can be deployed using Streamlit Community Cloud after uploading the required project files to a GitHub repository.

## Disclaimer
Predictions are estimates generated by a Machine Learning model and should not be treated as guarantees of future customer behavior.
